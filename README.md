# Football Question Answering Assistant

## Description

This project is an NLP-based Football Question Answering Assistant developed for the Natural Language Processing module.

## Team Members

* Eshan Menuka
* Tishan
* Disath

## Features

* Answers football-related questions using historical match data
* Uses machine learning and deep learning models
* Web-based interface

## Dataset

The project uses historical international football datasets including match results, scorers, penalty shootouts, and country name mappings.
